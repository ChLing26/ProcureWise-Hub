Design a beautiful, modern website UI for a wholesale stationery supplier comparison platform for small and medium-sized businesses.

Use the attached reference image as the main visual inspiration for the website's overall aesthetic.

Design Theme

A soft, pastel-colored aesthetic inspired by stationery, journaling, scrapbooking, and cute study planners.

Use a harmonious mix of pastel colors, with a warm, light background and gentle color accents.

Create a clean, airy, friendly, and visually appealing interface.

The design should feel creative and playful while remaining professional and suitable for business users.

Use rounded corners, subtle shadows, soft borders, spacious layouts, and delicate decorative details.

Use attractive typography with playful display fonts for headings and clean, readable fonts for other text.

Stationery Decorative Elements

Incorporate beautiful stationery-inspired illustrations throughout the website, such as:

Colorful paper clips.

Pencils and pens.

Rulers and set squares.

Sticky notes.

Notebooks and sheets of paper.

Erasers, binder clips, and washi tape.

Small doodles, hand-drawn lines, and subtle grid patterns.

Place these elements around page corners, section headers, empty spaces, and card edges. Use them as decorative accents without obstructing the main content.

UI Design Style

Create a cohesive design system that is consistent across all pages.

Make the navigation bar, sidebar, buttons, cards, forms, tables, and status labels visually consistent.

Give cards and panels a soft, paper-like appearance.

Use small stationery-themed icons where appropriate.

Design elegant buttons with rounded corners and subtle hover effects.

Make tables and data-heavy sections neat, organized, and easy to read.

Use gentle visual hierarchy, balanced spacing, and clear alignment.

Add subtle decorative backgrounds inspired by paper textures, graph paper, and stationery patterns.

Avoid excessive animations, clutter, overly bright colors, or childish cartoon styles.

Overall Impression

The website should look like a premium stationery-themed productivity dashboard mixed with a creative digital planner.

The design should be distinctive, charming, polished, and memorable, with stationery elements integrated naturally throughout the interface.

Prioritize visual design, UI consistency, readability, and user experience. Make the website responsive for desktop, tablet, and mobile.

Use creative freedom to choose a beautiful pastel palette and complementary typography. Do not restrict the design to specific colors.

Focus on the visual design only. Preserve the existing project structure and functionality, and do not invent or implement new business features. If the project already contains pages or components, improve their styling consistently rather than replacing the existing functionality.
