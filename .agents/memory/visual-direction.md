name: ProcureFlow visual direction
description: Project-specific palette direction for the procurement website.
---

ProcureFlow should use a soft pastel stationery theme, including light navigation surfaces, warm paper backgrounds, and gentle colored accents with readable dark text.

**Why:** The supplied project brief requested pastel stationery styling, and the user reaffirmed “soft pastel colour theme please” after the selected canvas layout introduced a dark sidebar.

**How to apply:** Preserve this palette when adapting canvas layouts. Layout approval alone should not replace the project's pastel visual direction with a dark navigation theme.
